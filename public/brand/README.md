# Brand Assets

This directory contains brand assets for Zimax Networks.

## Directory Structure

- `logos/` - Logo files (SVG, PNG in various sizes)
  - `zimax-logo.svg`
  - `zimax-logo.png` (various sizes: 16x16, 32x32, 128x128, 512x512)
  - `secairadar-logo.svg`
  - `ctxeco-logo.svg`
  - `opencontextgraph-logo.svg`

- `screenshots/` - Product screenshots
  - `secairadar/` - SecAI Radar dashboard and trust hub screenshots
  - `ctxeco/` - ctxeco platform screenshots

- `diagrams/` - Architecture and portfolio diagrams
  - `portfolio-overview.png`
  - `product-relationships.png`
  - `architecture-diagram.png`

## Usage Guidelines

- Logos should maintain aspect ratio when resizing
- Use SVG format when possible for scalability
- Screenshots should be high-resolution (at least 1920x1080)
- Diagrams should be clear and readable at various sizes
